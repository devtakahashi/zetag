Help

How do I create a request link?

Open Receive, enter your ZeTag and display name, then choose Create payment link. You can add an amount or note before sharing the link.

How do I connect my wallet?

Select Connect Wallet and approve the request in Phantom. Use the Phantom browser extension on desktop or open ZeTag in Phantom’s in-app browser on mobile.

Can I send USDC or link a Zelle Tag?

USDC transfers and Zelle Tag linking are currently unavailable. A request link can prefill the Send form.
