ZeTag interface and wallet-browser update

1. Extract the ZIP.
2. Upload its root files and the contents of profile and pay to matching
   paths in your existing GitHub repository. Choose Replace when prompted.
3. Copy pay/index.html into the local pay folder beside backend.
4. Run npx wrangler deploy from your existing local backend folder.
5. Wait for GitHub Pages to publish and refresh ZeTag.

This update applies over the combined tokens update already uploaded.
There are no new database changes.

Changes
- USDC/SOL controls sit at the right inside amount inputs and the wallet
  balance panel. Token selection uses a circular selected-dot indicator.
- A ringing bell replaces the old glyph. The violet notification dot stays.
- The profile dropdown has Profile and Connect entries with trailing icons.
- The saved profile avatar appears in desktop and mobile headers.
- Payment link and Payment page creation buttons share a row.
- The guide links and guide script have been removed from all three pages.

Wallets
Select a wallet, then tap Connect. On mobile, Phantom, Solflare and Backpack
open ZeTag in their built-in browser. Tap Connect there to approve once and
continue claiming or editing a profile inside that browser.
Jupiter's browser-opening link could not be verified. Selecting Jupiter
outside its browser copies the current ZeTag link and explains where to paste
it. Open Jupiter Mobile's browser, paste that link and connect from there.
Wallet Standard and injected providers are preferred when available.

Existing guide.js, wallet-mobile.js and vendor files can remain in the
repository. These pages no longer load the guide or direct handoff scripts.

Checks
Automated tests covered the three browser links, page-state preservation,
selection before connection, avatars in both header controls, token precision
and markup changes. Real wallet-app and phone visual checks remain pending.
This update does not add live payment transfers.
